# 읽기 전용 연동 계약

현재 SDK는 독립 빌드/테스트만 완료했고 MAUI 앱·서버리스 생성기에 연결하지 않았다. 기본 생성자 `new ReferenceCatalogClient()`는 Disabled이며 HTTP/디스크 읽기 0회다. 앱 화면 및 기존 서비스 등록을 변경한 파일은 없다.

1. 독립 작업이 `RefreshAsync`를 호출한다. 기존 발행 요청이 레퍼런스 완료를 기다리도록 연결하지 않는다.
2. Shadow는 서명/스키마/필수값/관계/해시를 검증하고 상태만 기록한다. `FindVerified`는 항상 null이다.
3. ReadOnly와 `AllowAiContext=true`가 모두 명시되어야 정확한 이름의 검수된 레코드를 반환한다. 이름이 여러 변형에 겹치면 추정하지 않고 null을 반환한다. 이미지 도메인은 반환하지 않는다.
4. HTTPS 동일 출처의 `reference/catalog/v1/active.json`과 서명된 상대 경로만 허용한다. 리디렉션을 따라가지 않는다. manifest 최대 64 KiB, catalog 최대 8 MB, 기본 제한 시간 4초(최대 10초).
5. 캐시는 서명 원문과 카탈로그를 한 파일에 저장한다. 쓰기 성공 후 메모리를 교체한다. 재시작 때 서명·해시·출처 URL·최대 30일 유효기간을 다시 확인한다.
6. DNS/5xx/타임아웃/빈 JSON/필수 키 누락/초안/서명·해시 오류/잘못된 관계/디스크 오류는 마지막 정상본을 유지한다. 정상 캐시가 없으면 참조를 생략한다. 상태 관측 콜백 오류도 격리한다.
7. OFF 전환 시 캐시가 있어도 노출하지 않는다. UI 기능, 이미지 요청, 뉴스 카드 생성, 푸시 전송 API는 이 SDK에 없다.

`config/features.json`은 배포 계약이며 자동으로 앱 설정을 덮어쓰지 않는다. 실제 연동 시 외부 설정을 읽는 호스트가 동일한 플래그를 적용해야 한다. 오래 실행되는 서비스는 인스턴스를 재사용하고 진행 중인 작업이 종료된 뒤 Dispose한다. 참조 결과를 브리핑 본문에 자동 추가하지 않는다.

운영에서 필요한 사전 조건: 검수/권한 승인 완료본, 고정 공개키, 실기기/서버리스 테스트 환경, 기존 발행·푸시·아카이브 회귀 통과. 화면 변경은 별도 승인 대상이다.
