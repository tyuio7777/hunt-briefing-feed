# 로드아웃 페이지 후속 반영 항목

이번에는 데이터 보강과 메인 상단 공식 정보 아이콘 복귀 위치 수정만 진행합니다. 아래 항목은 추가 확보한 자료를 근거로 정리한 후속 개발 범위이며, 기존 화면 변경 승인을 대신하지 않습니다.

## 연동 전 필수 확인

1. 전체 데이터에 기존 앱의 로컬 ID/저장 로드아웃 호환 검증.
2. 큰 검토용 JSON을 그대로 앱 시작 시 읽지 않기. 승인된 표시 필드만 소형 앱 카탈로그로 변환하고 로딩 실패 시 기존 로컬 자료 사용.
3. `staging/`을 기존 latest/index 피드 탐색에 포함하지 않기.
4. 새 데이터 검증·로드가 실패해도 페이지 뒤로가기, 메인 배치, 채널 알림, 브리핑 발행에 영향을 주지 않는 장애 테스트.
5. 이미지 권한과 전체 값 검증 후에도 원격 기능 기본 OFF에서 먼저 검사.

## 이번 공식 정보 아이콘 수정

NavigationPage의 네이티브 툴바 안에 있는 제목 영역과 페이지 본문을 서로 상대 측정해 오른쪽 여백을 계산하던 코드를 제거했습니다. 페이지 복귀·SizeChanged·Loaded 시 항상 기존 MainContentHorizontalInset(18dp)을 재사용합니다. 브리핑 채널과 로드아웃은 같은 복귀 경로에서 처리되며 클릭·연출·사이드바·드래그 로직은 변경하지 않았습니다. 실제 Android 기기의 반복 진입/복귀 검증은 아직 실행하지 못했습니다.
