실제 연구 파일 및 상세 누락 CSV는 비공개 전달 자료에 포함한다. 공개 저장소에는 집계와 검수 도구만 둔다. 공식 Steam 상품 정보로 스킨 후보의 명칭/분류/원형/출시일/DLC 관련 18개 필드를 교차 확인했고, 변형을 이름 접미사로 추정하지 않도록 변경 후보를 남겼다. 출처 확인과 공개 재배포 승인은 별개이다.

## 출처/권리 확인 기록 (2026-11-12 조사)

- [Bayou Index 소개](https://bayouindex.com/about/): 팬 제작 사이트이며 게임 자산/상표가 Crytek 소유임을 설명한다. 확인한 안내에서 일괄 수집·데이터 공개 미러링·이미지 재배포를 허용하는 명시적 근거를 확보하지 못했다. 허가가 없다고 법적으로 단정하는 의미는 아니다.
- [Crytek/Hunt 법적 안내](https://www.huntshowdown.com/legal): 게임 자산 권리를 확인할 자료. 이 페이지만으로 앱 이미지 재배포 허가를 부여하지 않는다.
- [Crytek 공식 Steam 상품](https://store.steampowered.com/app/4733620/Hunt_Showdown_1896_Bound_by_Blood/): 해당 상품의 개별 명칭/원형/출시 정보 교차 확인에 사용. 스토리·창작 설명문·이미지는 복제하지 않았다.
- robots.txt 조회는 성공하지 못했으며, 허용/금지 여부를 추정하지 않았다. API 제공 여부도 미확인이다.

`config/sources.json`의 대량 수집/모니터링/데이터 재배포/이미지 재배포는 모두 false다. 권리 검토 결과가 실제 문서 또는 승인 URL로 확보될 때까지 대량 크롤링과 공개 데이터 미러링은 실행하지 않는다. 게임 수치는 게임 버전과 플랫폼을 함께 검수해야 한다.

## 보강 순서와 완료 기준

1. 허가된 공식 자료/내보내기/API 범위와 수집 주기·속도 제한을 확인한다. 출처·허가 문서·허용 필드·재배포 조건·이미지 조건을 기록한다.
2. 무기 161개를 고정 ID로 대조하고 변형 관계 및 기본 성능을 검수한다. 무기별 지원 탄약 전부를 나열한 뒤 탄약별 가격/성능/효과/슬롯을 연결한다. 미지원도 확인한 경우에만 none으로 표기한다.
3. 도구/소모품 68개는 가격/지급 수량/사용 조건/지속시간/효과를, 특성 65개는 비용/획득/소멸/이벤트 조건/수치 효과/장비 관계를 확인한다. 장비 ID가 없으면 추정 연결하지 않는다.
4. 스킨은 공식 목록의 전체 범위를 먼저 확정하고 원형/명칭/획득 경로/기간/가용성을 검수한다. 동명의 서로 다른 원형을 허용하며 숫자 후보 개수를 전체 완성도로 보고하지 않는다.
5. 이미지는 항목별 소유자/라이선스 근거/표기 조건/변형 가능 여부를 확인한 뒤에만 로컬 자산·해시를 만든다. 미확인 URL은 후보 기록에만 남긴다.
6. 각 필드의 exact value digest를 증거에 연결하고 이전값/새값/조회일/이전 패치/새 패치/출처를 변경 후보로 남긴다. 승인 없는 수치 변경은 운영본에 반영하지 않는다.
7. 공개 후보의 필수값 검수율 100%, 존재하는 선택값 검수 100%, 도메인 범위 검수, 관계 검사, 출처별 공개 권리, 이미지별 권리, 테스트를 모두 통과해야 첫 운영 스냅샷을 서명한다.
