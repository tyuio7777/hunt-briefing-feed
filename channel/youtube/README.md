- 원본 제목을 유지하고 YouTube 영상 ID로 구분합니다. 제목이 같은 두 영상도 ID가 다르면 앱에서 각각 선택할 수 있습니다.

라이브 다시보기에서는 진행자의 첫 인사와 마지막 안내, 중간에 삽입된 예고편도 본편에 포함합니다. 방송 전후에 대기 화면만 이어진 것으로 확인한 구간은 분석에서 제외하고, 원본 재생 시각은 그대로 유지합니다.

원본 재생과 한국어 자료는 서로 다른 시점에 제공될 수 있습니다. 번역·요약 초안을 완성한 뒤에도 검토한 버전을 발행해야 앱에 표시됩니다.

## 앱에 반영하는 방법

1. 검토한 영상별 패키지를 `packages/<sha256>.json`에 업로드한 뒤, 원격 파일의 크기와 SHA-256을 확인합니다.
2. [카탈로그](catalog.json)의 해당 영상 항목을 새 패키지 경로와 제공 상태로 갱신합니다.
3. 앱의 **브리핑 채널 → 새로고침**에서 반영된 자료를 확인합니다. 같은 데이터 경로를 사용하는 앱은 APK 재설치 없이 발행된 자료를 읽습니다.

등록된 영상의 메타데이터는 30일 이내에 다시 확인해 갱신하거나 목록에서 제거합니다. 영상 AI를 사용하는 제작 작업은 확인된 무료 프로젝트·모델 범위에서 진행합니다. 공개 저장소에는 앱 배포용 JSON을 두고, 운영 인증 정보와 검토 중인 자료는 비공개로 관리합니다.
